# Playbook — executive presentations

Load when the route is pptx or the reviewed input is a deck.

## Principles
1. Recommendation and ask in the opening slide.
2. One logical argument, not a tour of the analysis.
3. One governing message per slide (STR-02).
4. Methodology, reconciliations and secondary cuts in the appendix.
5. Design for interruption: the story must hold if the executive jumps straight to risk,
   financials or implementation (STR-03) — restate the recommendation on each of those.

## Slide order (BUILD)
| # | Slide | Governing message | Must contain |
|---|---|---|---|
| 1 | Executive summary | The answer | Question · answer · ≤3 facts with comparators · ask · owner. Stands alone (FIN-01). |
| 2 | Situation → complication | Why this matters now | Only if the SCQ exception is invoked; one slide max |
| 3–5 | Evidence | One message title each | One chart or table per slide, annotated, comparator drawn, F/E/A/J tags in footer |
| 6 | Options and trade-offs | Why this option | Decision table: options (incl. BAU) × value · cost · risk · time. Restate recommendation. |
| 7 | Risk and uncertainty | What could change the answer | Ranges, sensitivities, assumptions with owners. Restate recommendation. |
| 8 | Decision required and follow-through | The ask | Exact ask · action · owner · timing · measure · next review |
| A | Appendix | — | Methodology, definitions, secondary cuts, source list with as-of dates |

## Expected-element list for absence checks (⊘)
Decision (slide 1) · Ask (slides 1 and 8) · Comparator on every number · Alternatives
incl. BAU (S2+) · Owner per action · Timing per action · Success measure · Next review ·
Assumptions register (S2+) · Range on every forecast.

## REVIEW specifics for decks
- Read every slide title first; grade each against TTL-01 before reading bodies.
- Count messages per slide (STR-02).
- Check that slides 6–8 (or their equivalents) each carry the recommendation (STR-03).
- Appendix content on a main slide → ORD-02 failure with the slide number.

## Title grading
| Grade | Example | Verdict |
|---|---|---|
| Weak | "Revenue performance" | Fail TTL-01 |
| Better | "Revenue finished 6% below plan as enterprise conversion slowed" | Pass |
| Strongest | "Reallocate acquisition spend to enterprise onboarding to recover the forecast gap" | Pass — prefer on decision slides |

## Speaker-note rule
Any fact that must be said but is not on the slide goes in the notes, tagged F/E/A/J,
with its source. Notes are not an appendix substitute.
