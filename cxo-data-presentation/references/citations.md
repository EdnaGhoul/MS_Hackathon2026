# Citations — public primary sources

Load when source discipline S2+ is active or the user asks for the evidence behind a
rule. Cite these in artefacts by author/title/year; include the URL only where a reader
link is wanted. These are all public. No private, tenant or personal-drive sources are
ever cited by this skill.

| Key | Source | Used for |
|---|---|---|

## Evidence standing (use when a user contests a check)
| Standing | Sources |
|---|---|
| Definitive (peer-reviewed experiment or formal standard) | Cleveland & McGill 1984; WCAG 2.2; ISO 24896:2026; SEC 1998 (for its domain); Green Book 2026; NIST CSF 2.0; UK IA templates |
| Strong empirical / foundational | Kaplan & Norton 1992; Porter & Nohria; Heer & Bostock 2010; Minto |
| Practitioner consensus | Salesforce QBR guidance; consulting-methodology QBR structure (eight sections, pre-wiring, "a scorecard that only shows green erodes trust faster than a red rating ever will", "watermelon" / all-green syndrome) |

Slide counts, KPI counts and specific thresholds are design heuristics, not
experimental findings. The skill never presents them as findings.

## Quotation rule
Quote a source only where the wording is on this page. Otherwise paraphrase and cite.
Maximum one short quotation per source per artefact.
