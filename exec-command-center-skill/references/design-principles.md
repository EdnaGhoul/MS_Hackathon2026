# Design principles for the executive brief

Grounded in: Minto Pyramid / SCQA (answer first), Amazon Weekly Business Review (same shape every
week, exceptions are the agenda, commitment chain), President's Daily Brief (ruthless curation, tailored
format), Endsley situation awareness (perception → comprehension → projection), IBCS / ISO 24896
(consistent notation), Cleveland–McGill (position > length > angle > area > colour), WCAG 2.2 SC 1.4.1
(never colour alone), Tufte / Few / Knaflic (data-ink, pre-attentive focus, action titles), and the
decision-first workflow DECISION → AUDIENCE → SIGNAL → STORY → VISUAL → ACTION → FOLLOW-THROUGH.

## The twenty rules

1. **Answer first.** Open with one governing claim someone could disagree with. Every section header
   carries its own one-line answer so a skipped-to section still reads correctly.
2. **Exceptions only.** RED/AMBER expanded; GREEN, FYI and CONTEXT counted and collapsed.
3. **Same shape every day.** Fixed section order, fixed encodings; the brain spends zero effort orienting.
4. **Colour + shape + word** on every status: ▲ RED, ◆ AMBER, ● GREEN, ■ CONTEXT. Never colour alone.
5. **Fixed, published thresholds** on every KPI tile; never tuned retrospectively. All-green → review
   the thresholds ("watermelon" guard).
6. **Every claim badged**: ✔ Verified (quoted + linked), ~ Inferred (pattern, no direct proof), ≈ Estimate
   (range). Inference is never presented as fact.
7. **Absence ≠ green.** No signals for an account is reported as "no new signals".
8. **Decision-first order.** Sections follow the decisions the executive makes, not the data sources.
9. **SCQA per decision**: Situation → Complication → Why now → If nothing changes by [date] →
   Recommendation → Ask.
10. **Why now** is mandatory: the cost of not deciding today.
11. **Projection** is mandatory on every risk: what happens by which date if nothing changes.
12. **Lens verbs** on actions — sales: Unblock / Reallocate / Change play / Reset commit; finance:
    Fund / Defer / Reallocate / Set conditions; technology: Prioritise / Accept trade-off / Retire / Invest.
13. **Leading before lagging**: what can still be changed today comes first.
14. **KPI spec** per tile: value · threshold · action that fires · decision served · trend (or
    "baseline forming").
15. **Commitment ledger** carries forward daily; items close only on evidence.
16. **Pre-reads must exist** and be linked; never "suggested reading".
17. **One-minute meeting brief** contract: stake · decisions needed from me · essential pre-reads ·
    five questions ranked by impact · if-we-run-out-of-time rule.
18. **Chart rules** (review day): line with target for trends, sorted bars for ranking, dot plots for
    actual-vs-target; no gauges, pies or dual axes; same chart shape every week.
19. **Design for interruption**: every collapsed header is a complete sentence.
20. **Method footnote**: state the rules, sources and counts so the reader can audit the brief.

## Audience lenses (framing differs, numbers don't)

| Lens | Primary framing | Emphasis | Call to action |
|---|---|---|---|
| CEO / board | Enterprise trajectory | growth, customers, strategic initiatives, reputation | direction, allocation, risk acceptance |
| CFO | Economic value and control | revenue quality, margin, cash, variance, forecast | fund, defer, reallocate, set conditions |
| CIO / CTO / CDO | Outcome enabled by technology | value delivery, resilience, security, adoption, debt | prioritise, accept trade-off, retire, invest |
| Sales / business | Attainment and future revenue | pipeline, conversion, slippage, renewal, concentration | unblock, reallocate coverage, change play, reset commit |
